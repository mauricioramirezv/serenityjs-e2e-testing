# Ejercicios propuestos

1. Agregue un escenario para una búsqueda sin resultados.
2. Implemente una tarea para retirar un producto del carrito.
3. Cree un endpoint `POST /api/cart` y automatícelo con `PostRequest`.
4. Use la API para preparar datos y la interfaz para verificarlos (blended testing).
5. Ejecute por separado las etiquetas `@web`, `@api` y `@smoke`.
6. Introduzca un defecto controlado, revise el reporte Serenity/JS y restaure la línea base.
